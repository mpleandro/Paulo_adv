# Imagens

- `paulo-hero.jpg` — Paulo de braços cruzados, hero
- `paulo-professor.jpg` — Paulo sentado, seção "Com quem você vai aprender"
- `colunas.jpg` — colunas do fórum, seção "Para quem é"
- `justica.jpg` — estátua da Justiça, chamada final

O CSS não aplica nenhum tratamento às imagens: o que estiver no arquivo aparece como
está, fundo incluído. Para o retrato do hero flutuar sobre o azul, como no layout,
exporte um **PNG com fundo transparente**. Ao substituir, mantenha o nome do arquivo.

Faltando algum, a página mostra um marcador no lugar e continua funcionando.
